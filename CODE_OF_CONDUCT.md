# Code of Conduct

Ce projet a une attente forte sur le **cohabitation** entre les membres
côté contribués et la communauté réutilisée (rustledger, egui, …).

## Engagement

À toute interaction (commentaires, discussions, tickets, échanges en privé),
les membres du projet s'engagent à :

- être **professionnels** et **respectueux** ;
- reconnaître les contributions anonymes ou connues ;
- ne pas utiliser de harcèlement, de menace ou de langage injurieux ;
- respecter le **respect du contenu** et, si la communauté n'est pas configurée,
  donner une chance à reformuler.

## En cas d'incident

- Si vous rencontrez un comportement contre ce code de conduite, signalez-le
  à un membre du projet en privé. Le comportement est potentiellement
  signalable auprès de la communauté pour les cas plus graves.

## Notifications

- Si vous êtes un membre du projet et que le code de conduite vous pose un
  problème, contactez-le.
- Si vous souhaitez consulter les pratiques, consultez la version
  actuelle sur GitHub.

Ce code de conduite est un **engagement** et pas une règlementation
légale ; ses indicateurs seront évalués par les membres.
